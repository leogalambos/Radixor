Dictionary-trained. Not dictionary-bound.

High-quality multilingual stemming.
Built for Java and Python.

Radixor learns word-to-stem transformations from lexical evidence, compiles them into compact tries of patch commands, and applies those transformations algorithmically at runtime. It combines deterministic results, small deployable models, and high throughput across 20 languages. The training dictionary supplies evidence—it does not define a closed runtime vocabulary.

What quality means here: the principal benchmark asks whether forms in the same annotated dictionary group—a morphological family, not a semantic or synonym set—receive the same stem, and whether forms with no shared group remain separated. Exact agreement with a prescribed dictionary root is reported separately. On this pairwise measure, Radixor ranks first in all 40 evaluated deterministic language-mode matrices, with no exact first-place ties; 38 include direct comparators and the two Hebrew modes report Radixor independently. The claim is limited to the published implementations, versions, adapters, dictionaries and metric. A separate 20-language, five-split experiment measures transfer to dictionary families withheld from Java model training.

import org.egothor.stemmer.StemmerPatchTrieLoader;
import org.egothor.stemmer.FrequencyTrie;

FrequencyTrie<CompiledPatchCommand> trie =
    StemmerPatchTrieLoader.loadCompiled(
        StemmerPatchTrieLoader.Language.US_UK, ...);

String word = "running";
CompiledPatchCommand patch = trie.get(word);
String stem = patch == null ? word : patch.apply(word);
